\cabstract{时序数据预测是数据分析中的重要任务，在电力负荷调度、交通流量管理和气象预测等场景中具有广泛应用。TimeMixer 是一种轻量级多尺度时序预测模型，通过多尺度分解与混合机制在预测精度和计算效率之间取得了较好平衡。然而，原始 TimeMixer 仍存在平均池化下采样可能丢失高频信息、固定窗口分解难以适应复杂周期变化、通道独立策略忽略变量间相关性等问题。针对上述不足，本文围绕 TimeMixer 模型进行了多尺度混合增强设计与实验分析。

本文主要完成了三个方面的工作。首先，设计了深度可分离卷积下采样模块，以可学习卷积替代固定平均池化，使模型在构建多尺度序列时能够更灵活地保留局部关键特征。其次，提出了多核门控分解模块，并行使用多个不同窗口大小的滑动平均操作提取趋势信息，再根据样本级全局均值特征生成门控权重，融合不同尺度的分解结果，以增强模型对多周期模式的适应能力。最后，引入低秩 MLP 形式的通道混合模块，在多尺度序列进入通道独立建模前进行浅层变量交互，从而在保持模型轻量化的同时增强变量间信息利用能力。

实验部分在 ETTh1、ETTh2、ETTm1、ETTm2、Weather、ECL、Traffic 和 Solar 等 8 个公开数据集上进行，预测长度设置为 96、192、336 和 720，评价指标采用 MSE 和 MAE。为分析不同模块的作用，本文以自跑 TimeMixer 结果 M0 作为基线，构造了 M1、M2、M3、M12、M13、M23 和 M4 等改进变体，完成了全组合消融实验，并结合公开整理结果补充了外部模型参考对比。实验结果表明，多核门控分解模块 M2 的综合表现最稳定，在多个数据集和预测长度上取得较好结果，是本文最主要的有效改进。深度可分离下采样和通道混合模块在部分场景中具有一定效果，但整体稳定性不足。完整模型 M4 并未在所有场景下取得最优，说明不同改进模块之间存在一定耦合关系。本文工作验证了多尺度混合增强思路在时序数据预测模型改进中的作用，也为后续轻量级预测模型的结构优化和应用分析提供了参考。}

\eabstract{Time series forecasting is an important task in data analysis and has been widely used in electric load scheduling, traffic flow management, weather forecasting, and other real-world applications. TimeMixer is a lightweight multi-scale forecasting model that achieves a good balance between prediction accuracy and computational efficiency through multi-scale decomposition and mixing. However, the original TimeMixer still has several limitations. Average pooling used in the down-sampling stage may smooth out high-frequency information, fixed-window decomposition is not flexible enough to handle complex periodic patterns, and the channel-independent strategy ignores correlations among variables. To address these issues, this thesis enhances the TimeMixer model from the perspective of multi-scale mixing and analyzes the effects of different modules through experiments.

The main work of this thesis includes three parts. First, a depthwise-separable convolution down-sampling module is designed to replace fixed average pooling with learnable convolutional operations, so that the model can preserve local key features more flexibly when constructing multi-scale sequences. Second, a multi-kernel gated decomposition module is proposed. It uses multiple moving-average kernels with different window sizes in parallel and generates sample-level gating weights from the global mean feature of each input sample, thereby fusing decomposition results at different scales. Third, a low-rank MLP-based channel mixing module is introduced before channel-independent modeling of multi-scale sequences to enhance interactions among variables while maintaining the lightweight structure of the model.

Experiments are conducted on eight public datasets from ETT, Weather, ECL, Traffic, and Solar. The prediction lengths are set to 96, 192, 336, and 720, and MSE and MAE are used as evaluation metrics. In this thesis, M0 denotes the TimeMixer baseline obtained in this work, while M1, M2, M3, M12, M13, M23, and M4 denote different ablation variants with one or more improvement modules. In addition to the internal ablation study, external baseline results from the reproduced results of the TimeMixer paper are used as a reference comparison, but the TimeMixer column in that file is not used; the TimeMixer baseline of this thesis is always the self-run M0 result. The experimental results show that the multi-kernel gated decomposition module, namely M2, achieves the most stable overall performance and is the most effective improvement in this work. The depthwise-separable down-sampling module and the channel mixing module are useful in some cases but are less stable across all datasets. The complete model M4 does not always achieve the best performance, indicating that there may be coupling effects among different modules. This work verifies the value of multi-scale mixing enhancement for time series forecasting models and provides a useful reference for further model optimization and application analysis.}
