\section{实验环境与参数设置}
\esection{Experimental Setup}

本文实验面向长序列多步预测任务，所有实验均基于 TimeMixer 模型及其改进变体开展。输入序列长度统一设置为 96，预测长度分别设置为 96、192、336 和 720。模型训练采用 MSE 损失函数，评价指标为 MSE 和 MAE。为保证消融实验的可比性，在同一数据集和同一预测长度下，除对应改进模块外，其余主要训练设置保持一致。

实验在 AutoDL 云平台的 NVIDIA GeForce RTX 4090 D GPU 环境下完成，软件环境包括 Python 3.10.8、PyTorch 2.1.2+cu121\cite{paszke2019pytorch} 和 CUDA 12.1。GPU 显存为 24564 MiB，驱动版本为 570.124.04，操作系统内核为 Linux 5.15.0-60-generic。本文实验采用固定随机种子 2021，各模型变体在相同设置下运行一次，相关结果用于消融对比和结构分析。

本文构造 M0、M1、M2、M3、M12、M13、M23 和 M4 共 8 个模型变体，在 8 个数据集和 4 种预测长度上进行实验，共形成 $8 \times 8 \times 4 = 256$ 个模型设置。M0 为 TimeMixer 基线，M1、M2、M3 分别对应单模块改进，M12、M13、M23 和 M4 用于分析模块组合效果。每个设置统计 MSE 和 MAE 两项指标，最终形成 64 个“数据集/预测长度/指标”评价场景。

\section{评价指标}
\esection{Evaluation Metrics}

本文采用均方误差（Mean Squared Error, MSE）和平均绝对误差（Mean Absolute Error, MAE）作为评价指标。设真实值为 $y_i$，预测值为 $\hat{y}_i$，样本总数为 $n$，则 MSE 定义为：
\begin{equation}
    \mathrm{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2.
\end{equation}
MAE 定义为：
\begin{equation}
    \mathrm{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|.
\end{equation}

MSE 对较大误差更敏感，能够反映模型是否出现明显预测偏差；MAE 直接表示平均绝对误差，更容易从整体误差大小进行理解。两项指标均为数值越低表示预测效果越好。本文在分析实验结果时同时观察 MSE 和 MAE，避免只依据单一指标作出结论。最优次数统计不是唯一评价标准，后续分析将结合完整结果表、平均结果和具体数据集表现共同讨论。

\esection{Baseline Model Comparison}

\subsection{对比基线模型介绍}
\esubsection{Baseline Models}

本节选取的公开基线覆盖多类典型时序预测模型。PatchTST\cite{nie2023time} 以时间片段为基本建模单元，强调 patch 化输入对长序列预测的作用；Autoformer\cite{wu2021autoformer} 将分解结构和自相关机制结合，用于捕捉周期模式；DLinear\cite{zeng2023transformers} 采用分解加线性映射的轻量结构；TimesNet\cite{wu2023timesnet} 从多周期角度构造二维时间变化表示；FEDformer\cite{zhou2022fedformer} 从频域角度建模周期信息；Crossformer\cite{zhang2023crossformer} 关注多变量时间序列中的跨维度依赖。这些模型覆盖了 Transformer、线性模型、多尺度周期建模和变量交互等方向，适合作为参考性横向比较对象。

\input{tables/main_results.tex}

从完整结果可以看出，M0 在多个数据集和预测长度上仍能取得最优或接近最优的结果，说明 TimeMixer 原有的多尺度分解混合结构本身具有较强的预测能力。以 ETT 系列为例，ETTh2、ETTm1 和 ETTm2 中有多处最优结果仍由 M0 取得，尤其在较长预测长度下，原始结构对趋势延续和周期信息的保持较为稳定。这一现象也说明，本文所加入的模块并不是对原模型的整体替代，而是在不同结构环节上进行局部增强；当数据维度较低、周期形态相对规则时，原始模型已经能够给出较稳的结果，新增模块的收益会受到数据集特征和预测长度的影响。

相比之下，M2 的优势更集中，最优项主要出现在 ETTh1、ETTm1、ETTm2、ECL 和 Traffic 等数据集上。其中 Traffic 的结果最具有代表性：在预测长度 96、336 和 720 下，M2 的 MSE 和 MAE 均取得最优；在预测长度 192 下，M2 的 MAE 与 M0 并列最优，MSE 也接近最优。Traffic 数据包含大量道路传感器序列，既有通勤周期等相对稳定的规律，也包含短时拥堵、路况变化等局部扰动。单一移动平均窗口在这种数据上容易出现尺度适配不足，而多核门控分解能够同时利用短窗口、中等窗口和较长窗口的趋势估计，因此在该数据集上表现更突出。

ECL 和 ETTm2 的结果则体现了另一类情况。ECL 中 M0 和 M2 在多个预测长度上的误差非常接近，M2 在部分 MAE 指标上略有优势，说明电力负荷序列中的周期性已经能被原始多尺度结构较好捕捉，多核分解更多体现为细微修正。ETTm2 中 M2 在预测长度 720 上取得 MSE 和 MAE 最优，在 96 和 336 上也有接近最优或部分最优结果，说明对于采样粒度更细、短期波动更明显的电力变压器序列，多窗口趋势估计能够在一定程度上缓解固定窗口分解的局限。

M1 和 M3 的结果相对分散。M1 在 Solar 的多个预测长度上误差较低，说明可学习下采样在周期明显且受外部扰动影响的数据中可能有助于保留局部变化；但在 ETTm2、Traffic 等数据集上，M1 的误差明显高于 M0 或 M2，表明可学习下采样并不总是优于平均池化。M3 在 Weather 和少数预测长度上取得较好结果，但整体优势不集中。Weather 数据变量之间存在气象物理联系，通道混合有发挥作用的空间；然而当前 M3 采用的是一次浅层低秩交互，对复杂变量关系的表达能力有限，因此没有在所有数据集上形成持续优势。

M4 包含三个改进模块，但从表 \ref{tab:main_results} 可以看到，它并没有在多数场景中取得最优。Solar 是 M4 表现较好的数据集，预测长度 192、336 和 720 下 M4 的 MSE 均为最优，说明在太阳能发电这类周期性较强且受扰动影响的数据中，多模块组合可能形成一定互补。不过，在 Traffic、ETTh2 等数据集上，M4 的误差并未低于 M0 或 M2。可能原因是三个模块同时改变了输入下采样方式、趋势估计方式和变量维度分布，使后续分解混合面对的特征形态更复杂，模型优化难度随之增加。因此，完整模型 M4 更适合作为模块组合效果的检验对象，而不能简单视为所有场景下的最终最优结构。

从预测长度角度看，短预测长度更依赖局部变化的拟合，长预测长度则更依赖趋势延续和周期结构保持。表中可以看到，不同变体在预测长度增加后的变化并不完全一致。例如 Traffic 中 M2 在短预测和长预测下都保持较好结果，说明多核分解对局部波动和较长趋势均有帮助；Solar 中 M4 在中长预测长度上更突出，说明组合结构对周期性能源序列的长跨度预测可能更有利；而部分 ETT 数据集在长预测长度下仍由 M0 取得最优，说明原始结构对低维规则序列已经具备较强的长期建模能力。由此可见，预测长度会放大不同模块的结构差异，主实验结果需要结合数据集类型共同理解。

从 MSE 和 MAE 两类指标看，部分场景中二者给出的最优变体并不完全相同。MSE 对较大的预测偏差更敏感，MAE 更反映整体平均误差水平。当某个变体只在 MSE 或 MAE 上占优时，说明它可能改善了某类误差表现，但未必同时降低所有误差形态。例如 Weather 和 ECL 中存在 MSE、MAE 最优模型不同的情况，这提示主实验分析不能只根据单一指标判断模型优劣。本文后续使用最优次数统计和平均结果表，也是为了从不同角度观察各模块的作用范围。

为了更直观地观察局部胜出场景中的误差差异，本文进一步计算了若干代表性结果相对 M0 的误差下降比例。例如，在 Traffic 数据集预测长度为 96 时，M2 的 MSE 由 M0 的 0.5181 降至 0.4621，下降约 10.8\%；MAE 由 0.3505 降至 0.2844，下降约 18.9\%。在 ETTh1 预测长度为 336 时，M2 的 MSE 和 MAE 相比 M0 分别下降约 8.0\% 和 5.4\%。在 Solar 数据集上，预测长度为 192 时 M4 的 MSE 相比 M0 下降约 18.2\%；预测长度为 720 时 M4 的 MSE 相比 M0 下降约 11.8\%。这些结果说明，在若干具体场景中，胜出变体相对 M0 的差异不仅体现在最优次数上，也能体现为较直观的误差下降。

\section{单模块消融实验分析}
\esection{Single-module Ablation Analysis}

为观察单个模块的独立作用，可以重点比较 M0、M1、M2 和 M3。M1 只替换下采样模块，M2 只替换分解模块，M3 只加入通道混合模块。表 \ref{tab:single_module_avg} 给出了四个变体在各数据集上的平均 MSE 和 MAE。

\input{tables/single_module_avg_results.tex}

在三个单模块变体中，M2 的整体表现更集中。它在 Traffic 上的平均 MSE 为 0.481、MAE 为 0.296，低于 M0 的 0.509 和 0.314，也低于 M1 和 M3。Traffic 数据中既有日常出行周期，也有局部突发拥堵，单一窗口分解难以同时覆盖这些变化尺度，多核窗口则提供了更灵活的趋势估计。ECL 中 M0 和 M2 的平均结果接近，二者 MSE 均为 0.183，MAE 分别为 0.273 和 0.272，说明 TimeMixer 基线模型已经能够较好处理电力负荷周期，但多核分解仍带来一定细微改善。

M1 的结果波动较大。深度可分离卷积下采样可以让模型学习下采样权重，有机会保留局部突变信息，但它也可能引入额外噪声或改变原始序列的平滑结构。M1 在 Solar 上取得较低平均误差，说明可学习下采样在受昼夜周期和天气扰动共同影响的数据中可能有一定作用；但在 ETTm2 和 Traffic 上误差上升，说明该模块并非在所有场景中都优于平均池化。

M3 的收益同样较分散。它在 Weather 上的平均 MSE 为 0.244，略低于 M0 的 0.245，但在 ECL、Traffic 等高维数据集上并未形成优势。一个可能原因是当前通道混合只进行一次低秩映射，对复杂变量关系的表达能力有限；同时，变量维度分布被改变后，也可能影响后续分解和跨尺度混合。

\section{实验结果讨论}
\esection{Discussion}

综合实验结果，本文主要得到以下几点认识。第一，多核门控分解带来的收益最集中。M2 获得 23 次最优，其中 MAE 最优次数为 13 次，高于其他变体。该模块直接作用于 TimeMixer 的分解环节，使模型能够利用多个窗口估计趋势项，并通过样本级门控权重融合不同尺度结果。第二，M0 获得 19 次最优，说明原始多尺度分解混合结构本身仍是较强基线。本文的改进结果更适合理解为对不同结构环节的对照分析，而不是简单的整体替换。

第三，M1 和 M3 分别获得 3 次和 4 次最优，说明可学习下采样和浅层通道混合在当前设置下只在少数场景中降低误差。后续若继续改进，可以考虑为 M1 增加更明确的平滑约束，或将 M3 从单次输入混合扩展为分层通道交互。第四，M4 只获得 5 次最优，低于 M0、M2 和 M12。这一结果说明，在轻量级时序预测模型中，多个结构模块同时加入后可能改变输入分布和优化路径，模块组合需要通过消融实验具体判断。

综合这些现象可以看出，本文实验更支持一种局部结构分析结论：在当前设置下，分解环节的改进贡献较集中，下采样和通道混合的收益更依赖具体数据特征。对于 Traffic 这类复杂周期数据，多窗口趋势估计更容易体现作用；对于 Solar，完整组合可能在周期与扰动并存的情况下形成一定互补；对于 Weather，浅层通道混合没有充分利用复杂变量关系；对于 ETT 系列，原始基线已经较稳，新增模块的收益呈现交替。

\section{本章小结}
\esection{Summary}

本章首先说明了实验环境、模型变体、主要超参数和数据集来源，然后介绍了 MSE 与 MAE 两项评价指标。在公开基线对比中，本文引入 TimeMixer 原论文公开结果，与 PatchTST\cite{nie2023time}、Autoformer\cite{wu2021autoformer}、DLinear\cite{zeng2023transformers}、TimesNet\cite{wu2023timesnet}、FEDformer\cite{zhou2022fedformer} 和 Crossformer\cite{zhang2023crossformer} 等模型进行参考性比较；在消融实验中，本文基于完整结果表、单模块平均表、组合平均表和最优次数统计表，对 M1、M2、M3 及其组合进行了分析。实验结果表明，多核门控分解模块在本文结果中贡献最集中，而可学习下采样、通道混合和完整组合模型的效果更依赖数据集特征。
